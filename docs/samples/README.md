# Sample portfolio artifacts

Reports generated from the fixtures, and the README screenshots taken from them. Run the commands from the repository root: the flaky and trends pages then show paths relative to the repo, not your home folder.

```bash
npm run analyze:report -- \
  ai/failure-analyzer/fixtures/sample-failure \
  --format html \
  --out docs/samples/sample-failure.html

npm run analyze:flaky -- \
  ai/flaky-detector/fixtures/flaky-then-pass.json \
  --format html \
  --out docs/samples/sample-flaky.html

npm run analyze:flaky -- \
  ai/flaky-detector/fixtures/flaky-then-pass.json \
  --out docs/samples/sample-flaky.md

npm run analyze:trends -- \
  --history ai/failure-trends/fixtures/sample-history.jsonl \
  --format html \
  --out docs/samples/sample-trends.html

npm run analyze:summary -- \
  --title "Playwright CI summary" \
  --suite smoke ai/flaky-detector/fixtures/hard-fail.json \
  --suite e2e ai/flaky-detector/fixtures/flaky-then-pass.json \
  --format html \
  --out docs/samples/sample-run-summary.html

npm run analyze:summary -- \
  --title "Playwright CI summary" \
  --suite smoke ai/flaky-detector/fixtures/hard-fail.json \
  --suite e2e ai/flaky-detector/fixtures/flaky-then-pass.json \
  --out docs/samples/sample-run-summary.md
```

`analyze:summary` exits with code 2 here because the sample has a hard failure; the files are still written.

`pr-comment-preview.html` is a hand-made preview of how GitHub shows the run-summary Markdown as a PR comment (not produced by a CLI).
